# On Hands app

1. GitHub par naya repository banayein aur ye saari files (.github folder samet) upload karein.
2. Repository me Actions tab kholein. "Build APK" apne aap chalta hai (ya "Run workflow" dabayein).
3. Kaam khatam hone par us run ke neeche Artifacts me "onhands-apk" download karein, zip kholein, aur app-debug.apk phone me install karein.

App ka naam/ID badalne ke liye capacitor.config.json me appName aur appId badlein.
